# Aplicativo de Cadastro de Clientes

Aplicativo Android desenvolvido para registrar novos clientes de uma loja virtual. O app permite realizar o cadastro de clientes durante eventos ou em lojas físicas, capturando apenas o nome do cliente inicialmente.

---

## 🏗️ **Tecnologias Utilizadas**
- **Linguagem:** Java
- **IDE:** Android Studio
- **Interface:** XML
